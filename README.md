# LoboDeals 3.2

LoboDeals is an English-language discovery site for PlayStation US games,
bundles, and DLC/Add-ons on PS4 and PS5.

The active project documentation starts at `AGENTS.md`. Read the seven
canonical documents listed there in order. Files under `docs/audit/**` are
historical evidence and must not be used as current operating instructions.

Local development uses `npm run dev`. Operational collectors, importers,
runners, Supabase writes, cache refreshes, push, and deploy require explicit
authorization.
