# LoboDeals audit evidence

Historical reference only. Do not use for current operations.

El proyecto activo es LoboDeals 3.2 y sus únicas fuentes vigentes están
enumeradas en `AGENTS.md`. Los nombres 1.9, 2.x, 3.0 o 3.1 dentro de esta
carpeta son rótulos contemporáneos a evidencia inmutable; no representan el
estado actual.

No modificar archivos incluidos en un manifest de recovery solo para cambiar
su título o añadir banners: sus bytes, tamaños y SHA-256 son parte del contrato
verificado. Consultar `LOBODEALS-CONTINUITY.md` para localizar cada evidencia.
